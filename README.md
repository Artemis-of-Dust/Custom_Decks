This is an online collection of custom-made assets for a variety of boardgames.

### Installation
Objects are created for use in Tabletop Simulator, which can be spawned in by the player through the **Custom Objects** menu. These are provided as `.json` files, which can be placed into the Saved Objects folder found under `/My Games/Tabletop Simulator/Saves/Saved Objects/`.

### Available Custom Decks
The released `.json` assets can be used in the following Tabletop Simulator modules:
- [Azur Lane Star Realms](https://steamcommunity.com/sharedfiles/filedetails/?id=3033360679)
- Exceed Fighting System](https://steamcommunity.com/sharedfiles/filedetails/?id=1430620409)
